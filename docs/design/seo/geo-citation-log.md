## Approach

Manual, no-cost check — no paid GEO-tracking tool (Otterly.ai, Semrush's AI
toolkit, Ahrefs Brand Radar). Once a month, ask each of the four target
engines every query below and log whether/how neuron shows up. Doesn't
block any other ticket in this map or in Site (2.5.0) — can start any time
after launch.

- **Engines**: ChatGPT, Claude, Perplexity, Google AI Overviews — the same
  four named when this map was chartered (crawler-policy Ticket 4 allows
  all of them to maximize AI visibility).
- **Cadence**: monthly.
- **What counts as a citation**: log the full spectrum, not a binary
  yes/no — a direct source link, a named-but-unlinked mention ("neuron, a
  memory tool for..."), or content clearly drawn from the site without
  attribution. Note which one it was per row.

## Query set

Fixed for comparability across months — same queries every check. Pulled
from [Ticket 1's keyword & search-intent research](keyword-search-intent-research.md);
only add a new query by editing this list deliberately, not per-check.

1. `claude code memory alternative to CLAUDE.md`
2. `context rot claude code`
3. `AI agent memory that stays in git, no cloud account`
4. `mem0 alternatives`
5. `issue tracker for AI coding agents`
6. `architecture linter for AI agents`
7. `neuron vs mem0`
8. `AGENTS.md vs CLAUDE.md`
